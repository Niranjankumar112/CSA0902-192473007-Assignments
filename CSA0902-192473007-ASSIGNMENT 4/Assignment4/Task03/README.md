Run `javac LibrarySearchScreen.java` then `java LibrarySearchScreen`. JFrame uses BorderLayout; search row uses FlowLayout; results JScrollPane is CENTER and expands; bottom navigation uses FlowLayout in SOUTH. Capture small, medium and large window screenshots. GridBagLayout offers more constraints but more setup; absolute positioning is fragile on resize/font changes. Layout computation depends on component count; nested panels add a few containers but improve maintainability.
