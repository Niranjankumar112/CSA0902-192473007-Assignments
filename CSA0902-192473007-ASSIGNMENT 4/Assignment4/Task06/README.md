Layering: EventRegistrationApp (Swing view/handlers) → RegistrationService (validation) → RegistrationDao (JDBC). Register and table loading use SwingWorker so database work is off the Event Dispatch Thread. A UNIQUE(student_id,event_name) key rejects duplicate registrations at database level. Starter loads first 100 rows using LIMIT/OFFSET and exports the displayed rows to CSV; extend with page controls and event filtering for the full brief.

Setup: execute `sql/event_registration.sql`; add MySQL Connector/J JAR; set EVENT_DB_URL (e.g. jdbc:mysql://localhost:3306/campus_events), EVENT_DB_USER and EVENT_DB_PASSWORD. Windows compile/run: `javac -cp ".;mysql-connector-j-x.jar" EventRegistrationApp.java` then `java -cp ".;mysql-connector-j-x.jar" EventRegistrationApp`. Never commit credentials. Test normal, invalid, duplicate, unavailable DB and CSV export.
