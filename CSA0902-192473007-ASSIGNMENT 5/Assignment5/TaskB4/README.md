Migration reads the seven-field file, validates field count, route, amount and ISO date, records invalid lines in a rejection report, then calls PassLoader so valid records load in one batch transaction. DatabaseInspector uses DatabaseMetaData to print product/driver versions and table names. Configure CO5_DB_URL, CO5_DB_USER and CO5_DB_PASSWORD and include Connector/J on classpath. The migration starter expects comma-separated fields and does not implement escaping for commas in names; document this limitation or extend the parser consistently with A1.
